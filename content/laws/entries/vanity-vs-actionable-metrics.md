A vanity metric makes you feel good. An actionable metric changes a decision.

**How to use it.** Before adding a metric, ask "what would I do differently if this number doubled? If it halved?". If the answer is "nothing", it is a vanity metric. Track it if it makes you happy, but do not pretend it informs the work.

**How it gets misused.** Used to dismiss any metric that is hard to act on. Some lagging indicators are how you keep score, and they are not vanity metrics. The test is intent as well as immediate use.
