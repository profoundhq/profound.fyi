The first 90% of the code takes 90% of the time. The last 10% takes the other 90%.

**How to use it.** The last 10% is fitting things together, polishing, handling edge cases, making it fast enough, making it secure. Plan it as its own phase.

**How it gets misused.** Treated as a doomy fact of life. It is a budgeting input. Plan for it.
