title: Hick's Law

slug: hicks-law

The time it takes to make a decision grows with the number of options.

**How to use it.** Reduce options to speed decisions. Apply it to user interfaces, command-line tools, configuration files, API surfaces, and meeting agendas. Three good options beat ten okay ones.

**How it gets misused.** Used to argue for hiding options entirely. The aim is to shrink the decision in front of the user while keeping the capability. A tool with fewer visible defaults can still have full power for those who need it.
