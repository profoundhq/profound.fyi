**How to use it.** For each piece of work, estimate what it costs to ship it a week later. Use that to set the order of work. The items with the highest cost of delay go first, whatever the effort.

**How it gets misused.** Estimated in detail, then ignored. The number does not have to be precise. A rough order of magnitude is enough to change priorities. The value comes from using it.
