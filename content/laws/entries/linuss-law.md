Given enough people looking at the code, every bug becomes obvious to someone.

**How to use it.** True for popular open source projects on common code paths. Code review and pair programming use the same idea on a smaller scale.

**How it gets misused.** As a reason not to test. The Heartbleed bug sat in widely used code for two years. Many eyes are not necessarily careful eyes.
