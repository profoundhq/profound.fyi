---
title: "Harvest a session into a module after its second run"
order: 500
updated: 2026-10-12
tags:
  - enabling-teams
---


**When:** You have run the same session for a second team, and it worked both times.

**The action:** Harvest it into a reusable 4Cs module. Capture what changed between the two runs as much as what stayed the same.

**Forces:** Harvesting after the first run codifies a draft. Waiting longer means the session lives only in your head and can't be run by anyone else. The effort comes when you would rather start the next engagement.

**Signals:** Someone else runs the module without asking you how. The second facilitator's run lands about as well as yours did.

**When not to:** The session worked because of who facilitated it. If only the slides would survive harvesting, write down what the facilitator did instead, or accept that it isn't reusable yet.
